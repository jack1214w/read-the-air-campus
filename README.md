# 讀空氣校園系列

仿《大家一起來閱讀空氣》的台灣校園版小遊戲。黑白線條小人，紅色的那個是你。

**線上遊玩：** https://jack1214w.github.io/read-the-air-campus/

## 兩個系列

**第一系列・校園日常篇（10 題）**：看懂氣氛，做出最不尷尬的反應。營養午餐排隊、走廊遇到老師、老師的冷笑話、傳考卷、拍畢業照……最後算出「空氣讀取率」。

**第二系列・將心比心篇（5 題）**：讓學生親身感受不被尊重的感覺，再換位思考。每關分成「體驗 → 猜心 → 行動」：

1. 作品分享時間：上台被批評，再猜小美的心情，最後選一句話
2. 老師在講規則：規則被聊天聲蓋住，再換你忍住不跟同學玩
3. 「先聽我說完」：發表被插嘴，再換你當聽眾
4. 同學答錯了：答錯被偷笑，再猜小宇的心情、選反應
5. 分組討論：一直插不進話，再換你當組長，找出沒說到話的同學

前面關卡的選擇會影響後面（例如讓小美難過，她之後就不肯上台）。每關結束有「討論卡」，方便投影給全班討論。

## 怎麼用

單一 HTML 檔，不需要伺服器或安裝。只有字型會連 Google Fonts，離線時自動改用系統字型。手機、平板、電腦都能玩，支援淺色與深色模式。
